# Local Crop Rescue Images

The application uses local images when present and displays styled placeholders otherwise. Supply optimized JPG files with these names to populate the hero and crop cards:

- `hero.jpg`
- `maize.jpg`
- `potato.jpg`
- `tomato.jpg`
- `cassava.jpg`
- `beans.jpg`

No external image URLs are used at runtime. Keep source images reasonably sized; the UI caches resized JPEG versions in memory.
